# PR용 화면·사용자 흐름 근거

PR 근거 수집을 요청받았을 때 메인과 QA 담당자가 읽는다. QA는 실제 캡처와 관찰을 반환하고, 업로드와 PR 본문 편집은 `create-pr`이 맡는다. 별도 QA 문서는 기본으로 만들지 않는다.

## 변경 전·후 화면

- 모든 화면 캡처는 설치된 `ego-browser` 지침에 따라 **ego lite**에서 수행한다. 변경 전 캡처는 해당 코드를 수정하기 전에 확보하고, 후에는 최종 검증 대상을 캡처한다. 기존 자료가 같은 버전·상태의 실제 캡처라면 재사용할 수 있다.
- 화면 크기, 경로, 권한, 데이터와 상태를 가능한 한 맞춘다. 기본 화면 외에는 변경을 판단하는 데 필요한 빈 상태·오류·반응형 등의 경우만 추가한다. 비교 조건이 다르면 무엇이 다른지 기록한다.
- 변경 전·후 이미지의 절대 파일 경로, 구분, 실행한 코드 버전 또는 작업 상태, URL·화면 조건을 메인에 전달한다. 민감한 쿼리 값은 제외한다. 이전 자료를 후속 캡처로 덮어쓰지 않는다.
- 변경 전 화면을 놓쳤다면 실제 이전 코드를 별도의 작업 공간·서버에서 확인할 수 있을 때만 보충한다. 사용자 작업 트리를 되돌리지 않는다. 이전 기능이 없거나 실행할 수 없으면 그 이유를 남긴다. 시안·생성 이미지·변경 후 화면을 변경 전 캡처처럼 사용하지 않는다.

## 사용자 확인 흐름과 진입 위치

실제 사용자 동작을 확인해야 하면 접속 환경과 필요한 권한·테스트 데이터, 시작 URL 또는 메뉴, 번호 순서의 행동과 각 단계의 기대 결과를 반환한다. 저장·변경 동작은 필요한 경우 다시 열기나 새로고침까지 확인한다. 직접 실행한 단계와 아직 실행하지 않은 제안을 구분한다.

진입 위치가 찾기 어렵거나 요청받았다면 ego lite에서 시작 화면을 캡처하고 버튼·메뉴 영역을 표시한다. 원본은 보존하고 표시본을 별도 파일로 남긴다. 예를 들어 실제 페이지의 확인된 요소 위치에 클릭을 가로채지 않는 임시 사각형·번호를 얹어 별도로 캡처한 뒤 즉시 제거할 수 있다. 표시 외에 UI 내용이나 결과를 바꾸지 않으며, 표시본임을 설명한다. 표시가 불가능하면 원본과 텍스트 위치 설명을 반환하고 그 한계를 밝힌다.

## 보관과 전달

현재 작업의 임시 증거 폴더에 보관하고, 생성한 서버·브라우저를 정리할 때 캡처 파일을 지우지 않는다. 계정값·토큰·개인 데이터가 보이지 않는 테스트 상태로 캡처하며, 업로드 전에 원본과 표시본 모두 확인한다.

메인에 이미지 경로와 비교 조건, 시작 화면·표시 대상, 사용자 확인 순서, 실제 검증 결과와 빠진 근거를 간결하게 반환한다. 파일을 만들었는지와 이미지 내용이 해당 화면인지 직접 확인한다. 경로만 있거나 브라우저 조작이 성공했다는 응답만 있는 상태를 검증 완료로 보고하지 않는다.
